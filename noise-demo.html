noise lab

Test page for js/noise.js. Every noise strip is drawn by the script from a seed, so the same seed always gives the same pattern. The strip under the logo uses the seed "noise guaranteed" and the page's wash colours, or the logo's six colours when there's no wash.

washes

Each page can take one tint from the combo 1 video by setting data-wash on its <html> tag. The wash colours the nav bar, cards, footer, any noise using the wash palette, and the colour fringes. Black text on every wash colour has a contrast of at least 8.5:1, above the 7:1 WCAG AAA level.

tape effects

tearing

Hover over the logo at the top, or tab to it with the keyboard, and it tears like a tape catching. It runs for under half a second. The logo is small enough to fall under the WCAG 2.3.1 size limit for flashes, so it can run quickly. Bigger images, like this photo, are slowed to three frames a second. Hover over it to compare:

The real image always stays in the page, so screen readers still get its alt text. If your system asks for reduced motion, nothing tears.

colour fringe

Add class="fringe" to a large heading for the offset ghosts from the video, in the wash's colour pair. It's only for big text, since at small sizes the ghosts blur the letters. It turns off for people whose system asks for more contrast.
