janko keyboard

Each row is a whole-tone scale. The rows next to it are a semitone higher, shifted half a key. So every scale and chord has the same shape in every key. Slide a finger to glide across notes.

Settings has a chromatic layout too, where each row is a semitone above the last, so chromatic scales run straight up.

No touch screen? Play rows Z and A, then Q and 1 an octave up. Space is sustain.
